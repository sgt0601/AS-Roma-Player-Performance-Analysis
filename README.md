# AS-Roma-Player-Performance-Analysis (2023-2024 season)

### Overview

This project analyzes AS Roma players' performance during the 2023–2024 football season using Python and statistical methods.

### Objectives

Explore relationships between expected goals (xG) and actual goal contributions.

Visualize player performance using statistical charts.

Apply linear regression to estimate goal contributions.

Identify players performing above or below model predictions.

### Tools

-Python

-Pandas

-Scikit-learn

-Matplotlib

-Seaborn

### Methods

-Data cleaning and preprocessing

-Exploratory data analysis

-Data visualization

-Linear regression modeling

-Residual analysis

### Dataset

Player statistics obtained from FBref.

### Project Background

Completed as part of STAT 107: Data Science Discovery at the University of Illinois Urbana-Champaign.
